# apex step 2 - Session manifest (full contract)

## Contract

`bash skills/apex/scripts/create-session.sh --cc-session-id "$(bash skills/apex/scripts/get-cc-session-id.sh)"`. `create-session.sh` captures the current branch as `base_branch`, creates a fresh git worktree at `<main-worktree>/.apex-worktrees/<session>/` on branch `apex/<session>` off HEAD, cd's into the worktree, and persists `worktree_path` / `branch` / `base_branch` in the manifest. All subsequent /apex steps operate inside the worktree (isolated `.claude-tmp/apex-active/`, isolated working tree, isolated index). Worktree dep bootstrap is layered (Layer 1 `create-session.sh` symlinks gitignored caches + `.env*` from main; Layer 2 optional `docs/apex-bootstrap.sh`; Layer 3 `verify-build.sh` `--frozen-lockfile` fallback at step-10). Cleanup at step 13/14/SessionEnd forks via `cleanup-session.sh` (clean+no-commits -> `git worktree remove --force` + `git branch -D`; else keep, warn awaiting `/apex-merge`). Integration of `apex/*` back into `base_branch` is owned by `/apex-merge` (manual; `skills/apex-merge/SKILL.md`). Nested-worktree / detached-HEAD / non-git-repo guards refuse to mint.
   - exit 0: `{session}` token to stdout; manifest written + producer-validated. **Token provenance (hard gate)**: thread ONLY the exact stdout `{session}` token into each `cd <main>/.apex-worktrees/{session}/...` - never fabricate it. Right after exit 0, `test -d` the worktree; if absent, HARD STOP + re-read stdout (fabricated token -> parallel-batch cascade).
   - exit 1: unrecoverable error (bad args, openssl missing, nested-worktree, detached HEAD, etc.); surface stderr to the user and abort cleanly (no manifest written, skip session-end-hook).

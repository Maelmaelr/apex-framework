## Contract

Agent `agents/discoverer.md` (Sonnet). Discovery cache check fires first via `bash skills/apex/scripts/discovery-cache.sh check <original_prompt> <project_root>` - hit -> reuse cached scope, write scope-check pointer, skip cascade. Cache key = `sha1(normalized_prompt + project_root)`, layout `.claude-tmp/apex-discovery-cache/<sha1>.json` + `<sha1>.head` sidecar (HEAD sha at write); `normalize_prompt` lowercases + collapses whitespace + trims, THEN strips path tokens for generic prompts but PRESERVES the plan path and salts with `plan-snapshot=<plan-sha>` for `continue:/implement: <plan.md>` pointers so an evolving plan hashes per-snapshot rather than colliding on the path-stripped prompt (recipe owned by `scripts/discovery-cache.sh`). TTL 7 days OR HEAD diverged > 10 commits. Miss -> layered cascade (LSP -> `discovery-expand.sh` -> screener gate); spawn-prompt seeds = regex tokens from `original_prompt` + `hypothesis.discovered_paths` + lessons paths + project-context paths + `project_root` (subagents do NOT inherit working memory; orchestrator propagates explicitly). All deterministic Glob/Grep sibling/consumer/doc expansion runs in ONE `bash skills/apex/scripts/discovery-expand.sh "$project_root" --seeds {session}-seeds.txt --goals {session}-goals.txt --prompt {session}-prompt.txt --out {session}-expand.json` call (replaces the ~14 LLM-driven prose clauses that pushed the single discoverer agent past 100 tool calls); it emits `{candidates,doc_surface,presplit_targets,delete_only_hint,caps}`, is purely additive + existence-filtered, and never finalizes scope. Keyword extraction inside it uses the canonical recipe (lowercase + tokenize on whitespace+punctuation + drop stopwords + drop tokens shorter than 4 chars + dedupe across goals; no AI keyword emit). Screener top-K scales by `goals.length` (1 -> 15; 2-5 -> 30; >5 -> 50; default 30 when goals absent). Screener is an inner subagent spawned by `discoverer.md`. Output: `{session}-main-scope.json` (for code+docs work `allowed_files` MUST already fold in the **doc-surface** set at scope-finalization - this is `discovery-expand.sh`'s `doc_surface[]`: goal-named docs plus the `docs/**` / `docs/architecture/**` / `.claude/rules/**` files matched by basename/subsystem against any kept code path, AND when ANY feature doc path enters the set its directory siblings - EVERY other `*.md` in the same dir (not just `index.md` / `README.md` / `overview.md`) - auto-join too because the documentation agent routinely cross-refs them - never via a reactive step-12 expand), AND when any goal edits a hook (`hooks/<name>.ts(x)`) that has a co-located `__tests__/hooks/<name>.spec.tsx` (or sibling `<name>.test.ts(x)`) asserting the hook's public behavior, `discovery-expand.sh` emits that test file as a `spec` candidate to pre-empt mid-verify scope expansion + scope-check pointer (write to THIS worktree's `.claude-tmp/apex-active/{session}-scopes/{cc_session_id}.txt`, never the main worktree's path - the hook reads from the calling worktree only); cache write via `bash skills/apex/scripts/discovery-cache.sh write` after a non-empty cascade result. Cascade-empty -> agent returns `{cascade_empty: true}`; orchestrator runs AskUserQuestion (`abort` | `proceed-with-discovered-or-prompt-paths`); dismiss/cancel = abort. Both empty -> abort runs `session-end-hook.sh` inline.
